# 📋 Todo App

Современное и удобное приложение для управления задачами.

![Скриншот](https://amirsho1991.github.io/todo-app/preview.png)

## ✨ Возможности

- ➕ Добавление новых задач
- ✅ Отметка задач как выполненных (зачёркивание)
- 🗑 Удаление задач
- 💾 Автоматическое сохранение в браузере (LocalStorage)
- 📱 Адаптивный дизайн

## 🛠 Технологии

- **HTML5**
- **CSS3** (современный дизайн + градиенты)
- **Vanilla JavaScript**
